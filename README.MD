## The Girl In My Saved File

Demo: https://khanaaaaaa.itch.io/the-girl-in-my-saved-files

# What It Is

A short psychological horror game made in RENPY. You play as someone who starts a game and meets a girl named Yuna. At first, she seems like a normal character, but the more you interact with her, the more unsettling things become.

The horror is pretty psychological? The girl is aware about everything but can't do anything about it. (yk the kpop idol industry)

# Why I Made It

 I got inspired from a tiktok I saw about the dark kpop industry, and that one pixel webcam girl on Tiktok and got into making this. So, it's not horror as in jumpscares, but reading the inspiration should make it make sense? T-T

# How I Made It

Tech Stack:

- RENPY

Learnt more time working on the presentation, especially the main menu and the custom dialogue box. I wanted the game to look cute at first, then gradually feel more uncomfortable as the story progresses.

# What I Learnt and What I Struggled With

A simple game can feel different depending on how the text is presented. Getting the dialogue screen to work was a struggle but it turned out cute so it was worth the hassle.
